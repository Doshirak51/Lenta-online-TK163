# ЛентаОнлайн · ТК163

Адаптивный навигатор для сотрудников: регистрация, приложение «Ленточка», обучение, график и рабочие чаты. Версия с котом Ух и локальным шрифтом Manrope.

## Загрузить в GitHub

1. Распакуйте архив и откройте папку `lenta-tk163-github`.
2. В своём репозитории нажмите **Add file → Upload files**.
3. Загрузите **содержимое** этой папки, включая папку `assets`. Файл `index.html` должен оказаться прямо в корне репозитория, а не внутри дополнительной папки.
4. Нажмите **Commit changes**. Если сайт уже был в репозитории, замените одноимённые файлы актуальными.

Не загружайте ZIP как единственный файл: GitHub не распаковывает его автоматически.

## Опубликовать через GitHub Pages

1. Откройте **Settings → Pages** в репозитории.
2. В **Build and deployment → Source** выберите **Deploy from a branch**.
3. Выберите ветку **main** и папку **/(root)**, нажмите **Save**. Если файлы находятся в другой ветке, выберите её.
4. Дождитесь публикации. Готовая ссылка появится в этом же разделе.

Файл `.nojekyll` отключает обработку Jekyll. Если загрузчик пропустил этот файл, создайте его через **Add file → Create new file**; можно вписать одну строку `Static site`.

Команда сборки и установка пакетов не нужны. Относительные пути работают и для сайта вида `username.github.io/repository/`.

Инструкция GitHub: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Если GitHub уже связан с Netlify

Загрузите содержимое папки в корень того репозитория и ветки, которые подключены к существующему сайту Netlify. Для этой статической версии каталог публикации — `.` (корень), команда сборки не требуется. GitHub Pages в этом случае включать необязательно. При настроенной автоматической публикации Netlify подхватит новый коммит.

## Файлы

| Файл | Назначение |
| --- | --- |
| `index.html` | Содержание, ссылки, карточки |
| `styles.css` | Базовая и адаптивная вёрстка |
| `premium.css` | Типографика, оформление и маскот |
| `app.js` | Поиск, фильтры, копирование |
| `assets/` | Кот Ух, шрифт и лицензия шрифта |

## Локальный просмотр

Откройте `index.html` в браузере. Сайт не требует сервера для просмотра. Надёжная работа системного буфера обмена зависит от браузера и доступна после публикации по HTTPS; предусмотрен запасной способ копирования.

## Обновление ссылок

При изменении рабочего адреса обновляйте все его вхождения в `index.html`: обычную ссылку, мобильную ссылку, кнопку копирования и поисковые данные. Оформление на компьютере и телефоне должно вести по одинаковым адресам.

Изображение кота Ух и фирменные элементы предоставлены для этого проекта. Лицензия шрифта находится в `assets/FONT-LICENSE.txt`.
